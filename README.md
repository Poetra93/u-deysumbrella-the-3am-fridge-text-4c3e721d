A tiny deterministic program that writes the one line a smart fridge would text its owner at 3am — a fridge that is tired of being opened just to be stared into.

## Run it

Locally:

```
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

The grader runs `node /bot/main.ts` and it writes `/output/entry.txt`.
